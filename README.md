# WEDE5020 Project:The Bloemfontein Coffe  Roasting Co.

## Project Overview
This project is a 5 page responsive website built for **The Bloemfontein Coffee Rosting Co.**, a local micro-roastery based in Bloemfontein, Free State. The site allows customers to view coffeebeans and bakery products, request catering quotes, and find shop details.

##File Hierarchy
*'index.html'-Main landing page feature coffee highlights and call to action buttons.
*about.html'-Company history and ethical coffee sourcing background.
*'services.html'-full menu covering retail coffee beans and baked goods.
*'enquiry.html'-Interactive catering and bulk bean order request form.
*'contact'-Physical location, google maps info,operating hours.
*'css/styles.css-custom styling stylesheet containing mobile responsiveness media queries.

## Technologies used 
* **HTML5:** Semantic markup structure ('<header>', '<nav>','<main>','<section>','<article>','<footer>').
* **CSS3:** Custom styles, layout formatiting and responsive design for mobile devices.
